# QZ Tray do DEALER¹

Instaladores do [QZ Tray](https://qz.io) 2.2.6 com o certificado do DEALER¹ embutido, para imprimir cupons em https://onedealer.com.br sem o aviso "Allow/Block".

Baixe pelo botão **Instalar app** em Configurações › Integrações › QZ Tray, ou na página de [Releases](../../releases).

| Arquivo | Sistema |
|---|---|
| `qz-tray-dealer1-2.2.6-windows.exe` | Windows 10 ou 11 |
| `qz-tray-dealer1-2.2.6-mac-apple-silicon.pkg` | Mac com chip Apple (M1, M2, M3…) |
| `qz-tray-dealer1-2.2.6-mac-intel.pkg` | Mac com processador Intel |

O `SHA256SUMS.txt` de cada release traz o hash de cada arquivo.

Os instaladores não têm assinatura comercial da Microsoft ou da Apple:
- **Navegador:** se ele disser que o arquivo não é baixado com frequência, clique em ⋯ › Manter.
- **Windows:** clique em Mais informações › Executar assim mesmo.
- **Mac:** vá em Ajustes do Sistema › Privacidade e Segurança › Abrir Mesmo Assim.

O QZ Tray é software livre da QZ Industries (LGPL 2.1). Estes instaladores foram compilados a partir do código oficial, [qzind/tray](https://github.com/qzind/tray) na tag v2.2.6.
